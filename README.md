## 🧪 Model Development Workflow

</div>

<br/>

```mermaid id="khr8s4"
sequenceDiagram
    participant D as Dataset
    participant P as Preprocessing
    participant F as Feature Engineering
    participant M as Model
    participant E as Evaluation
    participant O as Output

    D->>P: Load raw data
    P->>P: Clean and transform data
    P->>F: Generate usable features
    F->>M: Train ML/DL model
    M->>E: Evaluate predictions
    E->>O: Save results / automate action
```

## 🚀 Getting Started

</div>

<br/>

### 1. Clone the Repository

```bash id="mddnj9"
git clone https://github.com/dhrumilrana25/Machine-Learning-Projects.git
cd Machine-Learning-Projects
```

### 2. Create a Virtual Environment

```bash id="7tr2d1"
python -m venv venv
```

### 3. Activate the Environment

#### Windows

```bash id="4kn4z8"
venv\Scripts\activate
```

#### macOS / Linux

```bash id="a8kizb"
source venv/bin/activate
```

### 4. Install Dependencies

```bash id="3694zd"
pip install -r requirements.txt
```

### 5. Open Jupyter Notebook

```bash id="i78lgv"
jupyter notebook
```
